## 2. Logo System

### 2.1 Wordmark — "Cymbal"

| Property | Specification |
|----------|---------------|
| **Typeface** | ITC Avant Garde Gothic |
| **Weight** | Bold / Demi |
| **Case** | Title case: capital "C", lowercase "ymbal" |
| **Special Character** | The lowercase **"y" is set in italic** while all other letters are upright/roman. The italic 'y' has a distinctive swooping descender that curves right and extends significantly below the baseline, giving kinetic upward-leaning energy |
| **Letterforms** | Pure geometric forms — circular bowls on 'a' and 'b', even stroke widths, rounded arches on 'm', clean vertical stroke on 'l' |
| **Allowed Colors** | **Black (#000000)** and **White (#FFFFFF)** ONLY |

### 2.2 Monogram — "((C"

| Property | Specification |
|----------|---------------|
| **Construction** | Three geometric elements, left-to-right: (1) a smaller crescent/arc shape — partial circle, concave facing right; (2) a second, slightly larger crescent/arc — also concave facing right, nested concentrically; (3) a large uppercase "C" letterform (~270° arc) matching the ITC Avant Garde "C" from the wordmark |
| **Visual Metaphor** | Sound waves/vibrations emanating from the "C" — reinforcing the "cymbal" sonic concept |
| **Reading** | Horizontally compact, reads as a unified mark "((C" |
| **Allowed Colors** | **Black (#000000)** and **White (#FFFFFF)** ONLY |

### 2.3 Logo Usage Rules

| Rule | Detail |
|------|--------|
| **Color restriction** | NEVER render wordmark or monogram in any color other than black or white |
| **Co-placement** | When wordmark and monogram coexist on the same surface, they must be at **opposing corners** and at **highly contrasting sizes** (one large, one small) |
| **Lockup prohibition** | NEVER combine monogram and wordmark as a single lockup side by side |
| **Size restriction** | NEVER use wordmark and monogram at similar sizes on the same canvas |

### 2.4 Logo Placement Patterns

- Wordmark: typically top-left or bottom-right of compositions
- Monogram: persistent bottom-left footer element on section dividers and pages
- On photography: white wordmark overlaid on image, positioned upper-right or bottom-right

## 3. Icon Grid & Shape System

### 3.1 Icon Grid Construction

| Property | Specification |
|----------|---------------|
| **Grid format** | Square canvas |
| **Grid subdivisions** | ~8–10 equal cells per axis |
| **Diagonal keylines** | Corner-to-corner X diagonals |
| **Circle system** | Hierarchical nested circles — 1 full inscribed circle + quadrant-centered medium circles + smaller harmonically-scaled circles |
| **Purpose** | All icon shapes must snap to grid lines, circle arcs, and intersection points |

### 3.2 Foundational Primitive Shapes

Three foundational shapes derived from the grid:
1. **Half-circle / Semicircle** — D-shape with flat edge and curved edge
2. **Stadium / Pill shape** — tall vertical rounded rectangle with 180° semicircular caps, ~3:1 height-to-width ratio
3. **Circle** — perfect circle, roughly half the diameter of the semicircle

### 3.3 Shape Library (~30+ shapes)

All shapes are rendered in **solid cobalt/royal blue (~#4355F5)**. The complete library includes:

**Primitives:** Circle, semicircle (multiple orientations), quarter-circle, square, rounded square (squircle), stadium/pill (horizontal and vertical), ring/donut (annulus)

**Composites:** Leaf/vesica piscis (almond/eye shape), fan/sector (~120–150° spread), teardrop/drop, arch/tombstone (rectangle with semicircular top), 4-point star/diamond star, crescent, comma/apostrophe, eye/marquise, horseshoe/open arch, egg/ovoid, dome/cap, rounded rectangle with one flat corner

**Shape Characteristics:**
- All derived from circles, arcs, and straight lines from the icon grid
- Corner radii always match grid-derived arcs — never arbitrary
- No outlines — all shapes are solid fills
- Shapes can be combined, rotated, scaled, and nested

### 3.4 Shape Usage Modes

| Mode | Description |
|------|-------------|
| **Shape as Logo** | Combined to create subsidiary brand logos (1–4 shapes per logo) |
| **Shape as Supergraphic** | Single shape used at massive scale as a dominant visual element |
| **Shape as Image Container** | Photography masked/clipped into brand shapes (arch, semicircle, etc.) |
| **Shape as Pattern** | Single shape rotated and tiled in regular grids to create tessellating patterns |

## 4. Subsidiary Logos

### 4.1 Subsidiary Logo Construction Rules

| Rule | Detail |
|------|--------|
| **Shape count** | Minimum 1, maximum 4 shapes per logo |
| **Shape proportions** | Shapes should share similar size and form |
| **Overall feel** | Simplicity and roundness |
| **Brand quality** | Approachability |
| **Shape type** | Geometric shapes (circles, rounded squares, etc.) |

**Don'ts:**
- ❌ Avoid sharp and overlapping shape combinations
- ❌ Avoid highly contrasting shape sizes
- ❌ Avoid combining too many shapes (max 4 per logo)

## 6. Typography

### 6.1 Font Family

| Role | Typeface | Source |
|------|----------|--------|
| **Primary & Only** | **DM Sans** | Google Fonts (open source, geometric sans-serif) |

> DM Sans has friendly letterforms that resonate with the Cymbal wordmark. Low contrast within each letterform provides high legibility at small sizes; geometric "quirks" maintain personality at display sizes.

### 6.2 Available Weights

| Weight | CSS Value | Usage |
|--------|-----------|-------|
| **Regular** | 400 | Display headlines (H1–H4), large display type |
| **Medium** | 500 | Smaller headlines (H5–H6), subtitles, body, captions, buttons |
| **Bold** | 700 | Available for emphasis (not assigned to a specific UI role) |

### 6.3 Complete Type Scale

#### Headings

| Level | Weight | Size | Usage | Case |
|-------|--------|------|-------|------|
| **H1** | Regular | **80pt** | Website page title only — **ONE per page** | Sentence case |
| **H2** | Regular | **60pt** | Website section title | Sentence case |
| **H3** | Regular | **48pt** | Website section title | Sentence case |
| **H4** | Regular | **30pt** | Web and mobile card title | Sentence case |
| **H5** | Medium | **24pt** | Mobile app bar title | Sentence case |
| **H6** | Medium | **20pt** | Button text | Sentence case |

#### Supporting Text Styles

| Style | Weight | Size | Usage |
|-------|--------|------|-------|
| **Subtitle 1** | Medium | **16pt** | Supporting title |
| **Subtitle 2** | Medium | **14pt** | Supporting title |
| **Body 1** | Medium | **18pt** | Descriptions |
| **Body 2** | Medium | **14pt** | Descriptions |
| **Caption** | Medium | **12pt** | Assistive text and form labels |

### 6.4 Letter Spacing & Line Height

| Context | Letter Spacing | Line Height |
|---------|---------------|-------------|
| Display Headlines (large) | **−4%** | **1.0** |
| Large Body / Title text | **−2%** | **1.2** |
| Body / Title / Captions | **0** (neutral) | **1.3** |

### 6.5 Type Pairing Rules

- Limit type sizes to **2 or 3 variations** at a time per composition
- Use **large size contrasts** to distinguish hierarchy levels
- Utilize **generous negative space** for legibility
- Use **Regular weight** at larger type sizes
- Switch to **Medium weight** for smaller headlines and body copy

## 7. Layout System

### 7.1 Grid System

| Property | Specification |
|----------|---------------|
| **Column count** | **12 columns** |
| **Grid type** | Flexible and scalable |
| **Column width** | Equal-width columns with consistent gutters |
| **Margins** | Grid sits **inside** any applied margins |
| **Hairline rules** | Thin solid vertical/horizontal rules aligned to grid — used as graphic dividers |

### 7.2 Negative Space & Breathing Room

- **Core design principle**: generous whitespace is mandatory
- Elements should "spread out" across screens
- Creates "a feeling of brightness and openness"
- ~50% or more of a layout can be intentionally empty
- Do NOT fill all available columns with content

### 7.3 Line Length & Text Width Rules

| Rule | Specification |
|------|---------------|
| **Body text max width** | ~4–5 columns of the 12-column grid |
| **Readability** | Copy must NOT extend across all 12 columns |
| **Alignment** | All elements must maintain clear alignment relationships |

### 7.4 Image Rules

| Rule | Specification |
|------|---------------|
| **Positioning** | Images can sit within margins OR bleed to the edge |
| **Multiple images** | Standardize sizes (e.g., all 2-columns wide) |
| **Organization** | Groups of images in clear grid patterns (e.g., 4-across rows) |
| **Grid-breaking** | Permitted occasionally, but objects should still relate to the column structure |
| **Avoid** | Mixing many images at different sizes without organizational structure |

### 7.5 Image-to-Text Ratios

- ~50/50 to 60/40 image-to-text splits
- Text constrained to narrow columns; images can span wider
- Large image blocks placed below or beside text areas

## 9. Typography in UI

### 9.1 Hierarchy Rules

- Use **size contrast** to give hierarchy to elements and messaging
- **Color changes** signal interactive elements or important information
- Clear distinction between larger messaging and smaller CTAs
- Large size contrasts help break down information in an orderly way

### 9.2 Color in UI Typography

- **Primary 300** (pops of color) signals interactive moments and grabs attention
- Color can emphasize content without changing scale
- **Positive financial values** displayed in Primary 300 (green for FSI)
- Neutral colors (Black, Neutral 700, 500) for standard text

### 9.3 Rules & Dividers

- Thin rules (hairlines) used to visually divide and organize information
- Vertical rules separate data columns (financial data, specs)
- Horizontal rules separate list items

## 10. Photography

### 10.1 Universal Photography Principles

| Principle | Detail |
|-----------|--------|
| **Overall mood** | Warmth and humanity |
| **Authenticity** | Natural, not overly staged — subjects engaged in relevant activities |
| **Source** | Stock photography as primary source |
| **Abstract imagery** | Permitted as supplementary (equipment close-ups, product patterns, data visualizations) |
| **Color treatment** | Natural color preservation with subtle tonal biases per industry |
| **Diversity** | Non-negotiable — ethnicity, age, gender, cultural background must be broadly represented |

### 10.2 Photography Categories

#### Spatial & Architectural
- Communicate context and environment through texture, action, emotion
- **Subjects**: Building close-ups, human interaction moments, aerial views of activity
- **Composition**: Strong symmetry, leading lines, geometric patterns, bird's-eye views
- **Tonal families**: Warm wood tones (amber, honey) + Cool neutrals (white, grey, glass)
- **Lighting**: Natural/ambient, deep depth of field
- **Orientation**: Mix of looking UP (atriums, spirals) and looking DOWN (aerial pedestrian shots)

#### Portraiture (Corporate)
- Polished and welcoming, faces centered in composition
- Captured in usual working environment with uncluttered-but-not-sterile backdrop
- **Lighting**: Soft, diffused front-lighting; no harsh shadows
- **Depth of field**: Shallow — subject sharp, background significantly blurred
- **Framing**: Head-and-shoulders to upper chest, consistent aspect ratio (~4:3)
- **Usage**: Cymbal employees or customer/user personas

#### Avatars (Casual)
- **Casual and unstaged**, captured in the moment
- Outdoor/lifestyle settings, not workplace-specific
- Natural outdoor light (golden hour quality)
- **Framing**: Tighter face crops, designed for circular or square avatar crops
- **Usage**: Profile images in demo UIs

#### Industry-Specific Imagery

| Industry | Color Bias | Subject Focus |
|----------|-----------|---------------|
| **HCLS** | **Blue tones** | Lab workers, medical procedures, DNA/molecular imagery, surgical environments |
| **Retail** | **Red tones** | Clothing on racks, warehouses, retail POS, product close-ups, colorful textiles |
| **FSI** | **Green tones** | Stock tickers, financial data screens, meeting rooms, smartphone trading apps, data centers |

### 10.3 Photography Don'ts

- ❌ Overly staged or posed imagery
- ❌ Sterile/clinical backdrops for portraits
- ❌ Cold, harsh lighting
- ❌ Heavily filtered or artificially color-graded images
- ❌ Imagery lacking diversity
- ❌ Imagery disconnected from work/activity contexts

## 11. Illustration

### 11.1 Illustration Style

| Property | Specification |
|----------|---------------|
| **Overall approach** | Geometric / Flat / Shape-based |
| **Construction** | Figures, objects, scenes built from basic geometric primitives (circles, ovals, rectangles, rounded rectangles, triangles, leaf/petal shapes) |
| **Rendering** | Flat — no gradients, shadows, or 3D effects. All shapes are solid, unshaded color fills |
| **Outlines** | **None** — forms defined by color contrast between adjacent shapes, not by drawn lines |
| **Complexity** | Simplified/abstracted real-world subjects reduced to essential geometric silhouettes |
| **Relationship to icons** | Geometry alludes to the icon grid, creating cohesion between illustrations and icons |

### 11.2 Color in Illustrations

- **High saturation**: Vivid, bold, fully saturated colors (not muted or pastel)
- **High contrast**: Adjacent shapes use distinctly different hues
- **Multi-color compositions**: Each illustration uses 5–10+ colors simultaneously
- **Brand-palette adherent**: Colors consistent with the Cymbal brand palette
- **Background colors**: Solid colored backgrounds (black, blue, white, olive, cyan, brown) filling the entire frame

### 11.3 Character/Figure Style

- Built from simple geometric shapes — circular/oval heads, rectangular/trapezoidal torsos, simplified limbs
- No facial features at typical reproduction scale
- Diverse skin tones represented
- Clothing rendered as flat, solid-color geometric blocks
- Slightly stylized proportions (large heads relative to bodies)

### 11.4 When to Use Illustrations vs Photography

> *"Illustration may be used instead of photography when we need to communicate more abstract concepts, e.g. when visualizing Cymbal's values, commitments, and responsibilities."*

- **Use illustration for**: Abstract concepts, brand values, commitments, corporate responsibility, conceptual storytelling, celebratory moments
- **Use photography for**: Concrete, real-world subjects where authenticity matters (default)

### 11.5 Illustration Composition

- Centered/symmetrical compositions for single subjects
- Scene-based horizontal arrangements for groups
- Full-bleed color backgrounds
- Tight cropping — subjects fill the frame; some extend beyond edges
- No borders or frames
- Large, bold shapes dominate — no fussy small details

## 12. Motion & Animation

### 12.1 Page Transitions

- Brand shapes used as **supergraphics** to create transitions between pages
- **Morph/expand animation**: Small circle grows into a large arch/semicircle that fills the viewport, revealing a new page
- Shape color corresponds to the industry/subsidiary color

### 12.2 Progress Indicators

| Type | Description |
|------|-------------|
| **Physics** | Wireframe geometry (dashed construction lines) animates to form solid filled shapes resembling the Cymbal logomark geometry |
| **Fill** | Abstract brand shapes grow/fill within a circular container (dark shapes on light tinted background) |

- Used for asynchronous actions that don't require page transitions
- Feature interaction between generic brand shapes and shape formations

## 13. Applications & Brand Touchpoints

### 13.1 Print/Editorial Layouts

- **Primary graphic device**: Large semicircular/arc shape used as photo mask and color block, bleeding off page edges
- CC logomark can be used at massive oversized scale as layout element
- Multi-column grid with thin vertical rule dividers
- Numbered sections ("01", "02") with lorem ipsum body copy
- Mix of photography and graphic elements on same spread
- Wordmark placement: top-left or bottom-right

### 13.2 Sub-Brand Print Collateral

Each sub-brand uses:
- Its own accent color applied to the arc/circular shape device
- The arc/circular shape is the unifying graphic element across all verticals
- Sub-brand logos always placed in top corners
- Headlines can overlay colored arc shapes (white text on color)
- Identical structural layout system, differentiated by color identity

### 13.3 Corporate Website

- **Hero section**: Full-bleed photography with white wordmark overlay, upper-right quadrant
- **Navigation**: Hamburger menu only (minimal chrome), left sidebar for interior pages
- **Footer element**: CC logomark persistent bottom-left
- **Interior pages**: Left sidebar nav with active state in bold, content area with text + media
- **Portrait masks**: Circular crop for leadership/team photos
- **Values content**: Flat illustration style (colorful, diverse, inclusive)

### 13.4 Digital Signage & Wayfinding

- Two-panel layout: white info panel (date/time/location) + black wayfinding panel (directional arrows)
- Bold stacked typography for date/time
- White geometric arrow icons for directions
- CC logomark prominent on information panel
- Grid-based layout with vertical and horizontal rule dividers

### 13.5 Corporate Merchandise

**Lanyard:**
- Black nylon strap with alternating white CC logomark and "Cymbal" wordmark, repeated

**ID Badge:**
- White card, portrait orientation, rounded corners
- CC logomark with holographic/iridescent finish (security feature)
- Employee photo + name + title + "Cymbal" wordmark
- Clean minimal layout

### 13.6 Mobile App UI

- **Themeable design system**: Identical layout and components with swappable color palettes
- **Header**: Dark industry color (Primary 500/700/900) as app bar
- **Buttons**: Outlined style (green/blue/red border + text) or filled
- **Charts**: Industry-color palette bar charts
- **Chat UI**: Alternating bubble colors (industry color for bot, light grey for user)
- **FAB**: Industry Primary 300 circle with white icon

### 13.7 Google TV / Monitor Interfaces

- Widescreen landscape format
- Card-based layout with generous white space
- Industry color applied to accents, CTAs, and arc shape elements

## 15. Quick Reference — Key Brand Rules Summary

> [!TIP]
> **For AI agents generating on-brand content, always ensure:**

1. **Logo colors**: Black or white ONLY — never colored
2. **Typography**: DM Sans exclusively (3 weights: Regular, Medium, Bold)
3. **Subsidiary wordmarks**: ITC Avant Garde Bold — never for general text
4. **Industry colors**: Blue = HCLS, Red = Retail, Green = FSI
5. **Shapes**: 1–4 rounded geometric shapes per composition, derived from the icon grid
6. **Photography**: Warm, diverse, naturalistic, industry-toned
7. **Illustration**: Flat, geometric, no outlines, high-saturation multi-color
8. **Layout**: 12-column grid, generous negative space (~50%), body text ≤5 columns wide
9. **UI corners**: 0px for navigation, 10px for cards/inputs, pill-shape for buttons
10. **Semantic colors are sacred**: Never swap with industry colors
11. **Arc/semicircle supergraphic**: The unifying visual device across all touchpoints
12. **Brand personality**: Approachable, warm, geometric, modern, human-centric
